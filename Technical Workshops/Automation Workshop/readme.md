## Introdução ao laboratório de automações com o Security Copilot

Nosso projeto de laboratórios ajuda você a começar a usar o Microsoft Security Copilot e oferece experiência prática na implantação e no uso do conector do Logic Apps em seus cenários diários.

## O que são Logic Apps e como usá-los no Security Copilot?

O [conector do Logic Apps para o Security Copilot](https://learn.microsoft.com/en-us/security-copilot/connector_logicapp) permite a integração perfeita entre os fluxos de trabalho do Logic Apps e o Security Copilot. Este documento apresenta as novas ações disponíveis no conector e exemplos de casos de uso que demonstram sua utilidade. Esses casos de uso incluem a automação de investigações de incidentes sinalizados pelo Sentinel, a detecção de tentativas de phishing por email e o tratamento de diversas questões de segurança.
Um aplicativo lógico do Azure inclui dois componentes principais:
- Gatilhos<br>
- Conectores

Casos de uso do aplicativo lógico: correção, enriquecimento, fluxos de trabalho empresariais, transferência de logs e aplicativo lógico que chama uma Azure Function.
