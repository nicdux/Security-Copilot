# Workshops técnicos do Microsoft Security Copilot

Boas-vindas à série de workshops técnicos desenvolvidos para aprimorar suas habilidades e seus conhecimentos no uso do Microsoft Security Copilot. O Microsoft Security Copilot é uma ferramenta inovadora que se integra perfeitamente às soluções de segurança da Microsoft e oferece aos usuários recursos avançados para automatizar respostas, gerar narrativas de segurança e muito mais, por meio de tecnologias avançadas de IA. Estes workshops são destinados a profissionais de segurança, administradores de sistemas e qualquer pessoa interessada em aproveitar o poder da IA para fortalecer sua infraestrutura de segurança.
