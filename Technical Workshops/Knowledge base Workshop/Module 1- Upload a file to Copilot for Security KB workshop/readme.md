## Carregar um arquivo no Security Copilot
#### ⌛ Tempo estimado para concluir este laboratório: 100 minutos
#### 🎓 Nível: 100 (iniciante)

#### Objetivos

Ao concluir este guia técnico, você terá as seguintes habilidades:<br>

* Adicionar arquivos de exemplo ao Security Copilot.<br>


#### Cenário
"Neste workshop técnico, os participantes aprenderão a carregar um arquivo no Copilot for Security. Para concluir esta tarefa com êxito, você precisa atender aos seguintes pré-requisitos:<br>

* Você precisa ter seu próprio locatário e uma instância do Microsoft Security Copilot.<br>
* Acesso à pasta de arquivos de exemplo.<br>


# Agenda do workshop: carregar um arquivo no Security Copilot

# Agenda do workshop: workshop de base de conhecimento com carregamento de arquivo

- Visão geral do recurso de carregamento de arquivo
-https://learn.microsoft.com/en-us/security-copilot/upload-file

1. Verifique se o arquivo que você vai carregar está em um formato de texto comum, como DOCX, MD, PDF ou TXT, e se cada arquivo não excede 3 MB. Você pode carregar até 20 MB em arquivos no total.

2. Na página inicial do Copilot, selecione o ícone de fontes na barra de prompts para abrir a página Gerenciar fontes.

3. Selecione Arquivos para abrir a seção de carregamento. Você pode usar os arquivos de exemplo da seguinte [pasta](https://github.com/Azure/Copilot-For-Security/tree/main/Technical%20Workshops/Knowledge%20base%20Workshop/Sample%20Files).


![Cartaz Hunt Evil 2](https://github.com/Azure/Copilot-For-Security/blob/main/Images/KB%20Images/huntevilfileupload3.png)

4. Selecione Carregar arquivo para procurar seu arquivo.
Neste workshop, usaremos o seguinte arquivo de exemplo:
- Hunt Evil Poster SANS (SANS_DFPS_FOR508_v4.10_02-23 (1).pdf)

5. Aguarde o arquivo aparecer em Carregamentos. Se uma mensagem de erro for exibida, corrija o problema e tente novamente.

6. Para incluir o arquivo como fonte na sessão atual, alterne o botão ao lado do arquivo até que fique à direita (aceso). Se ainda não for usar o arquivo ou quiser excluí-lo como fonte da sessão atual, mantenha o botão desativado (à esquerda, em cinza).
