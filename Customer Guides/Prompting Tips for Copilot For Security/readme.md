# Dicas para criar prompts com o Microsoft Security Copilot

| Prática recomendada                                         | Descrição                                                                                                                                                                                                                                                                                                         |
|-------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Declare seu objetivo**                                   | O que você espera alcançar com sua consulta (prompt)? Informe ao Copilot o objetivo pretendido.                                                                                                                                                                                                                 |
| **Forneça contexto e defina expectativas**                | Seja específico e forneça contexto ao fazer perguntas, como o nome do plugin, da habilidade ou do promptbook que deseja usar. Preste atenção às palavras usadas nos prompts e a como elas podem afetar a resposta do chatbot. As palavras importam e podem influenciar a seleção de habilidades. Inclua modificadores como formato, público, extensão e confiança para orientar o modelo e evitar ambiguidades. |
| **Informe a fonte**                                | Indique no prompt a fonte das informações que procura, especialmente quando houver várias fontes capazes de extrair informações semelhantes.                                                                                                                                                                      |
| **Continue refinando**                               | Repita e refine os prompts se não obtiver os resultados esperados. Use palavras ou frases diferentes para fazer a mesma pergunta caso não obtenha o resultado desejado na primeira tentativa. O chatbot pode reconhecer melhor sinônimos ou expressões alternativas.                                                            |
| **Seja positivo e respeitoso**                        | Use instruções positivas em vez de negativas. Seja respeitoso e adequado ao ambiente de trabalho e evite conteúdo tendencioso, inadequado ou violento. Use linguagem neutra para se referir às pessoas e evite presumir gênero, funções ou sentimentos.                                                 |
| **Trate o Copilot como seu parceiro**                    | Dirija-se ao Copilot como "você", e não como "modelo" ou "assistente".                                                                                                                                                                                                                                                         |
| **Trate novas sessões do Copilot como se fossem desconhecidas** | Atualmente, uma sessão não pode consultar outras sessões. Isso significa que, se você fizer uma pergunta relacionada a uma resposta fornecida em uma sessão anterior, o Copilot provavelmente terá dificuldade para respondê-la sem contexto suficiente. Considere isso ao trabalhar com o Copilot.                                       |
| **Deixe o trabalho pesado de resumir suas sessões para o Copilot** | Ao concluir a sessão, use o Security Copilot para resumir as respostas dos prompts para o público que você escolher.                                                                                                                                                                                        |
| **Supere lacunas de conhecimento em KQL com habilidades NL2KQL e plugins KQL personalizados**     | Use o plugin de linguagem natural para KQL (NL2KQL) a fim de buscar informações em suas fontes de dados usando linguagem simples. Usuários iniciantes em KQL podem aproveitar nossos plugins KQL personalizados para executar consultas KQL comuns por meio de linguagem natural.                                                                                        |
| **Automatize sempre que possível**                        | Use promptbooks e promptbooks personalizados para automatizar fluxos de trabalho de segurança comuns que exigem respostas iterativas para reunir e resumir as informações procuradas.                                                                                                                                                  |
| **Tudo bem experimentar. Na verdade, isso é recomendável!** | Estamos explorando um território ainda desconhecido no mercado de LLMs de segurança. Não tenha medo de experimentar diferentes maneiras de formular os prompts e avaliar os resultados com base em suas necessidades e expectativas. Você pode se surpreender ao descobrir possibilidades que nunca imaginou. Compartilhe seus aprendizados conosco nos comentários do blog. |

**Dicas gerais**
1.	Verifique o menu de plugins para saber quais estão habilitados e quais habilidades oferecem.
2.	Selecione o ícone na barra de prompts para forçar o uso de um plugin ou promptbook específico, ignorar o orquestrador e obter resultados previsíveis.
3.	Examine os promptbooks disponíveis na biblioteca para entender como foram criados e quais entradas exigem.
4.	Use o recurso de promptbook personalizado para criar modelos de uma série de prompts que possam ser reutilizados em diferentes cenários ou com diferentes parâmetros.
5.	Use o painel para selecionar e resumir os prompts mais relevantes da sessão. Você também pode editar ou excluir prompts que não sejam úteis ou precisos.
6.	Use o log do processo ou o depurador para entender quais plugins são selecionados e executados e como eles enriquecem seu prompt.
Use o recurso de plugin personalizado para criar suas próprias habilidades e enriquecimentos com base em suas informações de segurança (por exemplo, logs personalizados) ou APIs.
