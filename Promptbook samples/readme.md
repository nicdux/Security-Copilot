# Biblioteca de Promptbooks de exemplo do Microsoft Security Copilot

Os Promptbooks do Microsoft Security Copilot contêm um ou mais prompts reunidos para realizar tarefas específicas relacionadas à segurança. Eles executam um prompt após o outro, aproveitando as respostas anteriores.

Você pode usar o construtor de Promptbooks para criar seu próprio Promptbook, automatizar fluxos de investigação e otimizar etapas repetitivas no Copilot de acordo com suas necessidades e requisitos.

**Documentação**
- [Usar Promptbooks | Microsoft Learn](https://learn.microsoft.com/en-us/security-copilot/using-promptbooks)
- [Criar seus próprios Promptbooks | Microsoft Learn](https://learn.microsoft.com/en-us/security-copilot/build-promptbooks)

**Pré-requisitos**
- Verifique se você tem o acesso e as permissões adequados para criar Promptbooks. [Entender a autenticação no Microsoft Security Copilot | Microsoft Learn](https://learn.microsoft.com/en-us/security-copilot/authentication)
