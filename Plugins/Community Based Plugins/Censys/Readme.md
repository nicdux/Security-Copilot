### Plugin personalizado do Censys

O Censys é um mecanismo de busca avançado, desenvolvido para que pesquisadores, analistas e profissionais de segurança explorem e compreendam o cenário da Internet, que está em constante expansão. Com um banco de dados abrangente e uma interface intuitiva, o Censys permite que os usuários descubram informações valiosas e avaliem a postura de segurança de redes, dispositivos e sites em todo o mundo.

### Instruções
#### Carregar o plugin personalizado

1. Obtenha o arquivo [Censys.yaml](https://github.com/Azure/Copilot-For-Security/blob/main/Plugins/Community%20Based%20Plugins/Censys/Censys.yaml) deste diretório.
2. Carregue o plugin personalizado.
3. Adicione a chave de API do Censys.
