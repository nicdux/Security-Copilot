# Plugin do Copilot for Security: IP-API

### **Este plugin permite enviar um endereço IP ao IP-API.com e obter diversas informações sobre ele.**

### Pré-requisitos

-   [Copilot for Security habilitado](https://learn.microsoft.com/en-us/security-copilot/get-started-security-copilot#onboarding-to-microsoft-security-copilot)
-   [Acesso para carregar plugins personalizados](https://learn.microsoft.com/en-us/security-copilot/manage-plugins?tabs=securitycopilotplugin#managing-custom-plugins)

### Instruções

#### Carregar o plugin personalizado

1.  Obtenha o arquivo IP-API.yaml deste diretório.
    1.  Carregue o plugin personalizado.

Para obter mais informações, consulte: plugin do Copilot for Security: [como usar o IP-API com o Copilot for Security](https://rodtrent.substack.com/p/using-ip-api-with-copilot-for-security)
