# Conjunto de plugins de enriquecimento
**Autor: Craig Freyman**

## Plugin IPEnrichment
Este conjunto de habilidades de enriquecimento de IP foi desenvolvido para aprimorar investigações de segurança, fornecendo informações sobre atividades relacionadas a IP. Essas ferramentas ajudam a identificar tentativas suspeitas de entrada, detectar ataques de força bruta e analisar anomalias de entrada associadas a endereços IP específicos.

### IdentifyFailedLoginIPs
Identifica endereços IP com tentativas repetidas de entrada com falha em várias contas. Destaca IPs com padrões de atividade suspeita, como ataques de força bruta ou tentativas de pulverização de senhas, e fornece métricas importantes, como a quantidade de tentativas com falha e de contas distintas atacadas.

Prompt de exemplo: identifique IPs com mais de dez tentativas de entrada com falha nas últimas 24 horas.
