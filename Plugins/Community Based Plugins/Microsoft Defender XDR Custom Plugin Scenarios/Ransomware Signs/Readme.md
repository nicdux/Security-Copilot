
### Plugin personalizado de indícios de atividade de ransomware

Boas-vindas ao plugin personalizado de indícios de atividade de ransomware! Aqui você encontrará uma habilidade que procura sinais de ransomware no Defender Advanced Hunting. Ela cria consultas que localizam artefatos individuais associados a ransomware e também pode executar consultas mais sofisticadas para procurar e ponderar indícios de atividade, identificando dispositivos que exigem atenção imediata.

#### Recursos:

- **TimeStampDays:** define a quantidade de dias do carimbo de data/hora para a consulta de busca de indícios de atividade de ransomware, incluindo:
        - 'Interrupção de vários processos usando taskkill.exe'
        - 'Busca de indícios de atividade de ransomware'
        - 'Verificação do ambiente em busca de atividade de ransomware'
        - 'Interrupção de processos usando net stop'
        - 'Exclusão de dados em várias unidades usando cipher.exe'
        - 'Limpeza de evidências forenses dos logs de eventos usando wevtutil'
        - 'Desativação de serviços usando sc.exe'
        - 'Desativação da Restauração do Sistema'
        - 'Exclusão de backup'
